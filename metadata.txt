about=FR: Recherchez simultanement dans les adresses (BAN pour la France, OSM/Nominatim dans le monde entier) et dans tous les champs de toutes les couches vectorielles de votre projet QGIS. Deux styles d'interface au choix : barre flottante deplacable et redimensionnable posee sur le canevas, ou panneau ancrable. Compatible QGIS 3.16 a QGIS 4 (Qt 5 comme Qt 6). Les resultats sont groupes par source, avec surbrillance de la geometrie au survol et zoom au clic. Un bouton "?" active un outil de geocodage inverse : cliquez sur la carte pour afficher directement dans le champ de recherche l'adresse BAN la plus proche (dans un rayon de 25 m). L'indexation est incrementale et non bloquante, et le resultat est conserve dans un cache compresse stocke a cote du fichier projet, avec empreinte par couche pour ne reindexer que ce qui a change. Interface traduite en 5 langues (FR, EN, ES, PT, DE). Un menu "vue de rue" ouvre, au clic sur la carte, la vue Street View/Mapillary/Panoramax/Bing Streetside du point dans le navigateur. Auteur : Yoan Laloux - https://www.linkedin.com/in/ylaloux/
    EN: Search simultaneously in addresses (BAN for France, OSM/Nominatim worldwide) and in every field of every vector layer of your QGIS project. Two UI styles: a draggable and resizable floating bar over the map canvas, or a dockable panel. Works on QGIS 3.16 through QGIS 4 (Qt 5 and Qt 6). Results are grouped by source, with geometry highlighting on hover and zoom on click. A "?" button activates a reverse geocoding tool: click on the map to show the nearest BAN address (within 25 m) directly in the search field. A "street view" menu opens, on map click, the Google Street View/Mapillary/Panoramax/Bing Streetside view of the point in the browser. Indexing is incremental and non-blocking, and is persisted in a compressed cache stored next to the project file, with a per-layer fingerprint so only changed layers are re-indexed. UI translated into 5 languages (FR, EN, ES, PT, DE). Author: Yoan Laloux - https://www.linkedin.com/in/ylaloux/

changelog=2.0.0
    - Compatibilite QGIS 4 / Qt 6 : le meme code tourne sur QGIS 3.16 a 4.x, sans branche separee
    - Nouvelle couche de compatibilite Qt5/Qt6 pour les evenements souris (core/qt_compat.py) : deplacement et redimensionnement de la barre flottante, outils de clic sur la carte
    - Enumerations Qt et QGIS toutes ecrites sous leur forme scopee (Qt, QgsRubberBand, QNetworkReply, QMetaType), seule forme acceptee par PyQt6
    - L'indexation ne demarre plus toute seule : un bouton de synchronisation dans la barre la declenche et affiche l'etat de l'index (rouge rien d'indexe, orange incomplet, ambre en cours, vert a jour)
    - Nouvelle option : restreindre la recherche aux couches cochees, sans cesser de les indexer toutes
    - Echelle de zoom configurable sur un resultat ponctuel (1:200, 1:500, 1:1000)
    - Code reorganise en paquets ui/, core/ et providers/
    - Le style d'interface "Panneau ancrable (Qt5)" devient "Panneau ancrable" : la preference enregistree reste valable
    1.5.0
    - Recherche jusqu'a 25x plus rapide : l'index passe d'un dictionnaire Python a des colonnes compactes balayees en C (90-590 ms par frappe -> 3-24 ms sur un projet de 870 000 valeurs)
    - Rechargement du plugin instantane : l'indexation ne demarre plus pendant initGui() et le cache est relu couche par couche, sans bloquer l'interface
    - Deduplication : une meme table chargee plusieurs fois dans le projet (copies, couches d'etiquettes) n'est indexee, stockee et gardee en memoire qu'une seule fois
    - Dates et nombres a decimales ne sont plus indexes par defaut ; une colonne typee decimale mais ne contenant que des entiers (numero de regard, diametre...) reste indexee, detectee au fil du parcours
    - Nouvelle option "Indexer aussi les dates et les nombres a decimales" dans la configuration
    - Nouveau format de cache : un dossier par projet, un fichier par index, conteneur binaire compresse en LZMA (pres de quatre fois moins de disque, relecture deux fois plus rapide)
    - Les preferences (style, langue, geocodeur, cache, opacite) sont memorisees globalement et ne sont plus perdues en changeant de projet
    - Le chemin du cache est cliquable dans la configuration et ouvre le dossier
    - Modifier les champs exclus invalide desormais le cache de la couche concernee
    - Correction : une seconde demande d'indexation n'annule plus celle en cours et ne refait plus le travail deja effectue
    - Le cache est reconstruit une fois a la premiere ouverture apres mise a jour
    1.4.0
    - Recherche de coordonnees brutes (WGS84 decimal ou Lambert93) directement dans la barre, au meme titre que BAN/OSM/couches
    - Nouvelle entree "Copier les coordonnees" dans le menu vue de rue (WGS84 + Lambert93 dans le presse-papiers)
    - Rayon du geocodage inverse configurable (defaut 25 m) dans le dialogue de configuration
    - Filtre BAN par code postal, configurable
    - Bouton historique (5 dernieres recherches) et bouton favoris (points enregistres, zoom rapide) dans la barre de recherche
    - Favoris et historique regroupes dans un menu "..." pour garder la barre compacte (la vue de rue garde son propre bouton)
    - Le repere du dernier point interroge par le bouton "?" reste visible sur la carte
    - Menus deroulants ("◎", "...") habilles avec la charte graphique de la barre flottante au lieu du style Qt generique
    1.3.0
    - Nouveau bouton "vue de rue" (menu deroulant) dans la barre de recherche : Google Street View, Mapillary, Panoramax, Bing Streetside
    - Choisir un service puis cliquer sur la carte ouvre la vue de rue du point clique dans le navigateur par defaut
    1.2.0
    - Nouveau bouton "?" dans la barre de recherche (barre flottante et panneau ancrable) : geocodage inverse BAN
    - Clic sur la carte apres activation du bouton "?" : affiche l'adresse BAN la plus proche (dans un rayon de 25 m) directement dans le champ de recherche
    - Message discret dans le champ (style attenue) si aucune adresse n'est trouvee dans le rayon

    - Lien vers le profil de l'auteur dans le dialogue A propos
    - User-Agent Nominatim lu depuis metadata.txt (conforme a la politique OSM)
    - README et description du plugin mis a jour

    - Floating bar (Maps) and dockable panel (Qt5) UI styles
